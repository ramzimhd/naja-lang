# Security

This experimental compiler has not completed HATCH safety or adversarial gates.
Do not compile or execute untrusted inputs in a privileged environment. Native
programs run with the invoking user's operating-system rights; process separation
is not a sandbox.

Do not post secrets or exploit details in public issues. Until the public
repository and its private reporting channel are configured, report concerns
directly to the project owner through an existing private channel. A private
GitHub security advisory channel is not yet claimed to be enabled.

There are no published supported release versions or response-time guarantees.
