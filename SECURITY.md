# Security

This experimental compiler has not completed HATCH safety or adversarial gates.
Do not compile or execute untrusted inputs in a privileged environment. Native
programs run with the invoking user's operating-system rights; process separation
is not a sandbox.

Do not post secrets or exploit details in public issues. Use
[GitHub private vulnerability reporting](https://github.com/ramzimhd/naja-lang/security/advisories/new).
The repository setting was enabled and verified on October 24, 2026. Reports go
to repository maintainers through GitHub; a GitHub account may be required.

There are no published supported release versions or response-time guarantees.
