- Concurrency/cleanup, events/subscription lifetimes, native execution and actual OS permissions.
- Numerical/effect correctness, shape checks, bounded resource behavior and honest optimization claims.
- Native session/version/resource behavior and independent AOT artifacts.

- Durable checkpoint/recovery, real ownership and no quota/billing/permission evasion.
