# Code of conduct

Treat contributors respectfully. Discuss code, evidence and technical decisions
without harassment, threats, discrimination or disclosure of private information.
Use constructive review and disclose conflicts of interest. Do not pressure
others to bypass security controls or misrepresent test results.

The project owner is responsible for moderation. Use an existing private contact
if available. Otherwise, open a repository issue requesting a private contact
route without including names, allegations or sensitive details. A dedicated
moderation address has not been published. No moderation team or response-time
guarantee is implied. Security vulnerabilities use the private route in SECURITY.md.
