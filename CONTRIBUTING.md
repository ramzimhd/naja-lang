# Contributing

Read AGENTS.md, START_HERE.md and the relevant technical specification before
making changes. English is required for official documentation, code comments,
public APIs and diagnostics. Preserve multilingual user data and test fixtures.

One integrator allocates non-overlapping paths and separate branches/worktrees.
Propose contract or requirement changes explicitly; do not weaken acceptance to
match an implementation. Keep all requirement IDs and previous evidence.

Use the pinned toolchain, run the relevant tests, and include exact commands,
target, exit codes and limitations. No Python belongs in the required build/test
chain. A local green test does not establish full grammar, safety, self-hosting
or release acceptance. Do not add secrets, private session output or hidden
generated implementation blobs.

Only submit material you are authorized to contribute under Apache-2.0. Disclose
third-party provenance and AI assistance. This document does not fabricate a
signed contributor agreement or DCO certification on anyone's behalf.
