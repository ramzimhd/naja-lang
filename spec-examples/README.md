# Proposed API and Syntax Contracts

These files describe requested interfaces. No compiler is supplied and no example has been executed as NAJA by this package. Move an example into the supported examples directory only after real compilation and acceptance.

Examples are English and may use optional depth markers/aliases. # %% is an editor comment convention, not new grammar. Data APIs are proposals under document 21 and require implementation/validation. Short source here is not a measured advantage over Rust/C++; document 22 requires matched working implementations and complete task-code accounting.

Document-authoring tools used to prepare this package are not dependencies of the future NAJA implementation. Do not copy the documentation generator into the mandatory NAJA build chain.
